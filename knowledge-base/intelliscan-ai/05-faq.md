IntelliScan AI - Frequently Asked Questions
General Questions

What is IntelliScan AI and who is it for?

IntelliScan AI is an AI-powered vulnerability scanner designed for developers, solo entrepreneurs, and organizations building modern applications. It's perfect for developers who want to ensure their applications are secure from vulnerabilities, exposed APIs, and misconfigurations before and after deployment. Our automated security testing platform is ideal for DevSecOps teams, startups, and enterprises.

How does IntelliScan AI detect vulnerabilities?

Our AI-powered vulnerability detection analyzes your application code, API endpoints, and configurations in real-time to identify security vulnerabilities, exposed sensitive data, and misconfigurations. IntelliScan scans for OWASP Top 10 vulnerabilities including SQL injection, XSS, and insecure authentication, plus modern threats like API security issues and cloud misconfigurations.

How is IntelliScan AI different from other scanners?

Unlike traditional vulnerability assessment tools, IntelliScan uses AI-powered analysis for more accurate detection with fewer false positives (99.7% accuracy). We're faster than enterprise tools (under 90 seconds average), more user-friendly than open source solutions like OWASP ZAP, and specifically designed for modern web applications and APIs.

Setup and Getting Started

How long does it take to set up IntelliScan AI?

The entire setup process takes approximately 5-15 minutes. Platform setup takes about 5 minutes, domain verification takes 5-10 minutes, and your first scan completes in under 90 seconds.

Do I need to install any software?

No. IntelliScan AI is completely cloud-based. You can access it from any web browser without installing software on your local machine.

How do I verify domain ownership?

Domain verification is required before scanning. You can verify ownership by either adding a DNS TXT record or uploading a verification file to your domain. The process is explained in detail in your dashboard after signing up.

Scanning and Security

Can I scan any website?

No. You may only scan domains that you own or have explicit written authorization from the domain owner. Unauthorized scanning is strictly prohibited and may violate applicable laws. IntelliScan reserves the right to suspend accounts that attempt unauthorized scanning.

How fast are scans?

The average scan completes in under 90 seconds. Scan time may vary depending on the size and complexity of your application and the depth of scanning (which varies by plan).

What types of vulnerabilities does IntelliScan detect?

IntelliScan provides 100% coverage of OWASP Top 10 vulnerabilities including:
- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Access Control
- Authentication failures
- Security misconfigurations
- Sensitive data exposure
- Command injection
- Path traversal
- SSRF and IDOR (Pro plan)
- Authentication bypass (Pro plan)
- And many more

How accurate are the scan results?

IntelliScan AI boasts a 99.7% zero false positive rate, meaning our AI-powered analysis provides highly accurate vulnerability detection with minimal false positives.

Can IntelliScan scan applications before deployment?

Yes! IntelliScan integrates seamlessly into your CI/CD pipeline for automated security scanning before deployment. Our DevSecOps integration catches vulnerabilities, exposed APIs, and misconfigurations early in the development process, preventing security issues from reaching production.

Features and Capabilities

Does IntelliScan provide continuous security monitoring?

Post-deployment continuous monitoring is planned for future releases. Currently, IntelliScan provides on-demand and scheduled scanning capabilities.

Can I integrate IntelliScan into my CI/CD pipeline?

Yes. IntelliScan offers API interfaces and integrations for popular CI/CD platforms including GitHub Actions, GitLab CI, Jenkins, and others. You can set up automated scanning on code commits or deployments.

Can I scan authenticated areas of my application?

Yes, with the Pro plan and above. Authenticated scanning allows you to test protected areas of your application that require login.

Does IntelliScan scan both frontend and backend code?

IntelliScan performs Dynamic Application Security Testing (DAST) on all plans, analyzing your running application. The Business plan includes SAST (Static Application Security Testing) integration for code-level scanning.

Can I export scan results?

Yes. All plans include the ability to export scan results for compliance and audit purposes.

Do you support multi-domain scanning?

Multi-domain support is available with the Business plan, allowing you to scan multiple domains and applications.

Yes. We use enterprise-grade security measures including end-to-end encryption to protect application data during scanning. Your scan results and application data are kept confidential and secure.

IntelliScan performs non-destructive security testing. However, as with any security testing tool, we recommend starting with development or staging environments before scanning production applications.

Troubleshooting

Why is my scan taking longer than 90 seconds?

Scan time can vary based on application size, complexity, and scan depth. Larger applications or deeper scans (Pro/Business plans) may take longer than the average 90 seconds.

Why can't I scan my domain?

Common reasons include:
- Domain verification not completed
- Domain ownership not verified
- Scan limit reached for your plan
- Domain belongs to someone else

Contact support if you're having trouble scanning a domain you own.

How do I interpret scan results?

Each scan result includes:
- Vulnerability name and description
- Severity rating (Critical, High, Medium, Low)
- OWASP category
- Affected locations
- Step-by-step remediation guidance

If you need help understanding results, contact our support team.
