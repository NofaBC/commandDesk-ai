CareerPilot AI - Features Guide
Overview

CareerPilot AI helps users manage their job search from one dashboard. The platform focuses on the practical parts of the job search process.

Current Features
1. Profile Builder

Users can build and update a profile with:

target role

location

country

years of experience

skills

background details

This profile is used throughout the platform.

2. Job Search + Fit Scores

CareerPilot AI can:

search for jobs

return matched job results

assign AI fit scores

display matched skills and relevant job details

Job search is one of the core credit-based actions.

3. Smart Apply

Smart Apply helps users:

generate an AI cover letter for a selected job

review the cover letter

copy it for use

track the application after applying

4. Resume Builder

Users can:

build a resume

edit resume content

export a PDF

The Resume Builder is always free to use.

Note: The builder currently uses a US / International English-style resume format.

5. Interview Coach

The Interview Coach supports:

General interview mode

Behavioral interview mode

Technical interview mode

It provides an AI-driven practice experience using the user’s target role and prior context.

6. Application Tracking

Users can track applications through the dashboard and see what jobs they have applied to.

7. Dashboard

The dashboard provides access to:

profile status

matched jobs

application activity

resume tools

interview tools

analytics (plan-dependent)

Not Included in Current Launch Scope

The following are not part of the current launch support set unless officially added later:

native mobile apps

LinkedIn optimization

salary negotiation tools

company research intelligence

video interview analysis

calendar integrations

broad multilingual resume generation

non-English job market support
